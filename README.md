# 🏠 House Price Prediction Using Machine Learning
A beginner-friendly Machine Learning project that predicts house prices based on various property features like bedrooms, bathrooms, square feet area, floors, condition, and more.

This project is built using **Python**, **Pandas**, **NumPy**, and **Scikit-Learn** with the **Linear Regression Algorithm**.
---

# 🚀 Project Overview
The goal of this project is to build a Machine Learning model capable of predicting house prices using historical housing data.

This project covers:
✅ Data Loading  
✅ Data Preprocessing  
✅ Feature Selection  
✅ Train-Test Split  
✅ Model Training  
✅ Prediction  
✅ Model Evaluation  

---

# 🧠 Machine Learning Algorithm Used
## Linear Regression
Linear Regression is a supervised machine learning algorithm used for predicting continuous numerical values.

In this project, it is used to predict house prices based on house features.
